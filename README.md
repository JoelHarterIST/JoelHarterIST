# Joel T Harter

Rocket R&D systems engineer at [Interstellar Technologies](https://www.istellartech.com/en) since May 2024, based in the Tokyo office. A major focus of mine is the **guidance** system — I wrote the guidance algorithm (and the supporting algorithms around it) for **Zero**, our orbital launch vehicle.

## Public Work

- Wrote [**istellartech/RocketToolBox**](https://github.com/istellartech/RocketToolBox) — a Julia toolbox of standard utilities for aerospace calculation and analysis
- Wrote [**JoelHarterIST/JuliaXC**](https://github.com/JoelHarterIST/JuliaXC) — a Julia-to-C transpiler for static array math, built so numerical algorithms can be authored in Julia and the C deliverable derived mechanically
