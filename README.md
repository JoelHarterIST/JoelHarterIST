# Joel T Harter

Rocket R&D systems engineer at [Interstellar Technologies](https://www.istellartech.com/en) from May 2024 to **13 August 2026**, based in the Tokyo office. My main focus there was the **guidance** system — I wrote the guidance algorithm, and the supporting algorithms around it, for **Zero**, their orbital launch vehicle.
