# ハーター　ジョエル

2024年5月より[インターステラテクノロジズ](https://www.istellartech.com)に勤務するロケットR&Dシステムズエンジニア。東京オフィス所属。業務の主軸は**誘導（Guidance）** システムで、当社の軌道投入用ロケット **Zero** の誘導アルゴリズム（および周辺の補助アルゴリズム）を開発。

## 公開している成果物

- [**istellartech/RocketToolBox**](https://github.com/istellartech/RocketToolBox) を開発 — 航空宇宙の計算・解析のための標準的なJuliaユーティリティ集
- [**JoelHarterIST/JuliaXC**](https://github.com/JoelHarterIST/JuliaXC) を開発 — 静的配列演算のためのJulia-to-Cトランスパイラ。Juliaで記述した数値アルゴリズムから、C言語の成果物を機械的に導出することを目的として設計
